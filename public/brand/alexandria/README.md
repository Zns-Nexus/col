# Col / Alexandria

Two proposed brand designs, generated with the built-in imagegen tool following the brandkit skill.

## Index

Keeps the three-tab Index symbol and develops an editorial archive identity around it. The tabs suggest a collection organized for discovery. The Alexandria idea lives in engraved archive imagery, printed textures, campaign typography, and publication layouts.

## Scroll

A new C symbol derived from an unfurling scroll, with two rolled terminals and a generous open center. It shares Col's rounded, approachable character while giving the archive theme a distinct mark.

## Continuity with the website

- Keep the Col name, black and white palette, rounded interface typography, sidebar, search, filters, and library grid.
- Use an editorial serif for brand presentations and campaign headlines. Retain the existing sans serif for product controls and reading.
- Introduce archive imagery in social graphics, campaign posters, and selected brand sections. Keep the directory focused on library content.
- Treat classical artwork as an imagined metaphor for collecting and sharing knowledge, not a reconstruction of the historical Library of Alexandria.

The boards and logo lockups are raster concepts. The application examples are illustrative. The live website has not been changed by this design exploration.
