# New Col logo concepts

Four monochrome raster concepts generated with the built-in imagegen tool, following the brandkit skill. These designs explore the logo itself without changing the website.

- **Folio:** an abstract pair of archive pages with a restrained fold cut.
- **Ligature:** a custom lowercase sans wordmark, with no separate emblem.
- **Colophon:** an editorial serif wordmark for a modern publishing and resource archive.
- **Junction:** separate catalog entries gathered around an open negative-space channel.

Each PNG shows one black logo on white. These are concept images, not production vector files. Exact prompts are in `generation-prompts.md`.
